# Personal Website for GitHub Pages

This repository serves a static personal website directly from the repository root for GitHub Pages.

## Publish URL

If this repository belongs to the GitHub account `xinxincodingc` and stays named `xinxincodingc.github.io`, the site will be served at:

`https://xinxincodingc.github.io/`
